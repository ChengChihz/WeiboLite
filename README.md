# 微博Lite · WeiboLite

为 **Nokia N9 · MeeGo 1.2 Harmattan** 改进的非官方微博客户端。

基于 [Karin 的 Weibo++ / Weibomm](https://github.com/glKarin/weibomm)，进行 2026 年可用性更新与界面调整，尽量保留 MeeGo 原生操作风格。

**[下载 1.0.0 安装包](https://github.com/ChengChihz/WeiboLite/releases/tag/v1.0.0)** 


## 主要更新

**界面：** 统一主页、用户主页、搜索热搜、消息等页面UI视觉，更新图标与开屏，新增深色模式、字号调整及图片加载设置

**功能：** 关注与推荐时间流切换、快捷转发评论点赞、正文评论预览与排序、微博热搜、新版微博表情、更新的图片查看器

**可用性：** 调整现有微博接口，增加应用私有 TLS 1.2 网络组件，改善官方登录验证与跳转，并提供电脑辅助登录



## 已知问题

动态验证码在 N9 上加载较慢且通过情况不稳定，部分账号可能遇到登录跳转失败，可使用辅助登录作为备选

辅助登录需使用电脑端微博，通过 Cookie 进行登录

安装、辅助登录及编译说明请查看仓库 README 和 docs，反馈请提交 Issues

## English

WeiboLite is an unofficial Weibo client for Nokia N9 running MeeGo 1.2 Harmattan, based on Karin's Weibo++ / Weibomm. This update refreshes the UI and adapts network access and login to current services. Includes timelines, profiles, search, posting, comments, image zoom, dark mode and computer-assisted session import. Tested on N9 PR1.3 only. Login and service availability may vary.
