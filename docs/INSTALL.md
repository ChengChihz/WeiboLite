# 安装与登录

## 安装

1. 使用 Nokia N9 · MeeGo Harmattan。本版真机测试环境为 PR1.3。
2. 从本仓库 Releases 下载 `WeiboLite_1.0.0_armel.deb`，通过 USB、蓝牙等方式传到手机。
3. 如系统要求，在「设置 → 应用程序 → 安装」中允许来自非应用商店的安装，再用手机文件管理器打开安装包，交由系统安装器安装。
4. 从应用列表打开「微博Lite」。

`armel` 表示安装包面向 N9 使用的 ARM 架构，不是语言标记。开发者模式不是普通安装流程的必需步骤；无需为本应用替换系统 TLS 库。

安装包版本为 `1:1.0.0`，应用内显示 `1.0.0`。前面的 `1:` 是 Debian 版本 epoch，用于使新版本号能覆盖旧 Weibomm 的版本编号。包名仍为 `weibomm`，属于原包的升级替代，不会与原包并列安装；不要先卸载来升级，以免影响现有数据。建议升级前备份重要数据。

## 官方登录

默认提供短信登录，也可以使用账号密码。安全验证由微博官方页面提供，需要本人手动完成。N9 网页引擎较旧，验证加载可能需要十几秒甚至更久；验证类型、能否通过与后续跳转均可能受服务端影响。

## 电脑辅助登录

多次无法完成验证时，可在登录页右上角打开「辅助登录」。

1. 在自己的电脑浏览器访问 **https://m.weibo.cn/**，完成官方登录。
2. 按 F12 打开开发者工具（Mac：Option + Command + I），切换到 **Network / 网络**，刷新网页。
3. 筛选 `config` 请求。列表可能有多个，确认所选请求属于 **m.weibo.cn**；如果没有，可查看同域的 `getIndex` 请求。
4. 打开 **Headers / 标头 → Request Headers / 请求标头**，找到 **Cookie**，右键复制它的 **value / 值**。不要复制整个请求或响应标头。
5. 将值存成 UTF-8 `.txt` 文件，通过 USB 或蓝牙传到 N9 的用户存储空间。
6. 在辅助登录页点「选择 TXT 文件」，选择文件，再点「验证并登录」。

Cookie 相当于登录凭证，仅导入你自己的手机，不要分享、上传到仓库或附在反馈中。应用会向微博验证会话；登录状态失效后，可能需要重新导入。导入后手机直接访问微博，无需保持电脑开机。
