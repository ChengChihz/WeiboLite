主要更新
本次 MeeGo 微博 Lite 改版的累计调整：

一、可用性与兼容性
• 适配现有微博数据、发布、评论、点赞和用户资料接口，修复内容、头像、来源与表情解析
• 增加应用独立的 HTTPS／TLS 1.2 兼容支持，保留证书校验，使 N9 能够连接现有微博服务
• 接入官方账号密码、短信登录与安全验证，改善验证框显示、资源加载及登录跳转
• 新增电脑辅助登录：将本人的电脑端登录会话通过导入 N9，作为官方验证受限时的备用方式

二、视觉及 UI
• 新设计的微博主页、用户主页、搜索与热搜榜单、消息等界面
• 更新应用图标、登录与开屏画面
• 新增深色模式
• 新增字号调整设置
• 优化启动展示、下拉刷新

三、功能调整与新增
• 微博主页提供关注与推荐时间流，并新增快捷转发、评论与点赞功能
• 更新用户主页，集中展示资料、微博、关注与粉丝信息
• 微博正文内加入评论预览，支持最新／热门排序，并可进入完整评论页
• 更新搜索页，加入排名、热搜预览及完整榜单入口
• 更新 127 个新版微博表情
• 图片查看支持双指缩放、拖动和缩放滑杆
